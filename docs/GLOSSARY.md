# Glossary

- API — route returning structured data, often JSON, to browser code.
- Argon2id — password hashing method that makes guessing expensive.
- Authentication — confirming who signed in.
- Authorization — deciding which actions a signed-in person may take.
- Callback — function called later when work finishes.
- Controller/handler — validates a request, does work, chooses response.
- CSRF — a trick that makes a signed-in browser submit an unwanted request.
- EJS — templates that combine HTML with server data.
- Environment variable — external setting such as DB_PASSWORD.
- Foreign key — database link/rule between tables.
- Flash message — brief feedback displayed after redirect.
- Hash — one-way transformed value; passwords are verified, not decrypted.
- HTTP-only cookie — browser cookie unavailable to page JavaScript.
- Middleware — request pipeline function that runs before route handler.
- Migration — SQL changing database structure.
- Multer — Express upload middleware.
- MySQL pool — reusable set of DB connections.
- Parameter placeholder (?) — value sent separately from SQL text.
- Route/router — mapping HTTP method and URL to middleware/handler.
- Session — server state linked to browser cookie.
- Socket.IO — live two-way connection for chat/alerts.
- SQL — language for reading/changing relational DB records.
- Transaction — DB operations committed together or rolled back.
- View/local — EJS template and named values passed to res.render.
